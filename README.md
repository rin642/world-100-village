# もし世界が100人の村だったら — 最新データから見る、世界の暮らし

2026年11月27日時点で利用できる最新の公的統計データをもとに、世界（約83.0億人）を「100人の村」に縮小して表現するインタラクティブなインフォグラフィック・Webダッシュボードです。

- **公開URL（Vercel）**: https://world-100-village.vercel.app/
- **GitHub リポジトリ**: https://github.com/rin642/world-100-village

## 技術構成

- **React** + **TypeScript** + **Vite**
- **Tailwind CSS v4**
- **Recharts**（棒グラフ・円グラフ）
- **Lucide Icons**（100人のアイコン表示・UIアイコン）

## プライバシー設計（「自分と比較する」機能）

- 入力された情報（年齢・居住地域・生活費・飲み水・識字・インターネット・母語・宗教）は **React のメモリ上の state のみ** で保持されます。
- **サーバーへの送信（API通信）は一切行いません。**
- **LocalStorage / SessionStorage / Cookie にも保存しません。** ページを閉じるか再読み込みすると入力内容は消去されます。
- すべての項目は任意入力で、未回答のままスキップして比較・結果画面へ進めます。
- 該当統計が存在しない項目（年齢の人口分布、未取得のL1母語統計）については「比較できない」旨を明確に表示します。

```bash
npm run dev

# リント・型チェック・本番ビルド
npm run lint
npm run build
```

## GitHubへの公開・デプロイ手順

### 1. GitHub リポジトリの作成とプッシュ

```bash
git init
git add .
git commit -m "Initial commit: もし世界が100人の村だったら ダッシュボード"
git branch -M main
git remote add origin https://github.com/<あなたのユーザー名>/<リポジトリ名>.git
git push -u origin main
```

### 2. GitHub Pages での公開（推奨：同梱の GitHub Actions を利用）

本リポジトリには `.github/workflows/deploy.yml` を同梱しており、`vite.config.ts` で `base: './'` を設定済みです。

1. GitHub の対象リポジトリページを開き、**Settings → Pages** へ移動します。
2. **Build and deployment** の **Source** を **GitHub Actions** に変更します。
3. `main` ブランチへプッシュすると自動でビルド＆デプロイが実行され、`https://<あなたのユーザー名>.github.io/<リポジトリ名>/` で公開されます。

### 3. Vercel / Netlify で公開する場合

- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- GitHub リポジトリを連携するだけで自動的にデプロイされます。
